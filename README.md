# OOAKOSIMO Pantry Alchemist

## Rebel’s Kitchen Propaganda

**Recipes, stories, kitchen experiments, edible memory and browser mischief from the pantry.**

**Pantry Alchemist** is an OOAKOSIMO browser-zine series built from whatever is already in the cupboard: recipes, ingredient histories, personal memories, kitchen accidents, small rituals and lightweight web experiments.

The project treats the recipe page as more than instructions. Each issue can become a little self-contained web object — part zine, part field note, part kitchen propaganda, part interactive artwork.

> **Small batch. High aroma. No supermarket fantasy required.**

## Issue 001 — Ginger Field

**Ginger · Clove · Cinnamon · Chamomile · Black Sesame · Oat Biscuits**

Issue 001 began as a recipe and wandered into a browser side quest. It combines:

## Portable by design

The work is kept deliberately lightweight and self-contained so the same folder can live on GitHub Pages, Neocities, IPFS, local storage, or another static host without rebuilding the artwork around a platform.

Core artwork dependencies use relative paths whenever possible. Social-preview metadata may point to an absolute hosted image because link-preview crawlers are considerably more needy than browsers.

Typical package:

```text
pantry-alchemist/
├── index.html
├── 404.html
├── not_found.html
├── p5.min.js
├── icon.png
├── share-card.png
└── README.md
```

## Series logic

**PANTRY ALCHEMIST** is the collection / world.  
**REBEL’S KITCHEN PROPAGANDA** is the attitude / imprint.

Future issues can contain recipes, food memories, ingredient obsessions, accidental experiments or whatever happens while OOAKOSIMO is supposedly doing something else.
